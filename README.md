# fetchurl/.github

Organization defaults for [github.com/fetchurl](https://github.com/fetchurl). GitHub applies these community health files to public org repositories that do not ship their own copy.

| File | Role |
|------|------|
| **[profile/README.md](./profile/README.md)** | Organization profile README (shown on the org page) |
| **[CONTRIBUTING.md](./CONTRIBUTING.md)** | Where to file issues and pull requests across the multi-repo project |
| **[SUPPORT.md](./SUPPORT.md)** | Help routing (docs, usage questions, security vs public issues) |
| **[SECURITY.md](./SECURITY.md)** | Default vulnerability reporting policy |
| **[.github/ISSUE_TEMPLATE/](./.github/ISSUE_TEMPLATE/)** | Default bug and feature issue forms, plus contact links |
| **[.github/PULL_REQUEST_TEMPLATE.md](./.github/PULL_REQUEST_TEMPLATE.md)** | Default pull request body (right-repo check, protocol vs impl, tests) |
| **[LICENSE](./LICENSE)** | MIT license for these org defaults (aligned with product repos) |
